# CapsLock Switcher RS 输入法切换工具

CapsLock Switcher RS由Rust开发，旨在安全稳定，解决AHK版的闪退问题。这是一个轻量级的输入法切换工具，允许你使用 CapsLock 键在中英文输入法之间切换，类似于 macOS 上的行为。消除了使用 Shift 键切换输入模式的不便。

## 功能

- **CapsLock 切换**: 按下 CapsLock 键在中英文输入模式之间切换
- **Alt+CapsLock**: 按下 Alt+CapsLock 可触发原本的锁定大写功能
- **视觉反馈**: 显示提示通知，指示当前语言模式
- **系统托盘集成**: 右键点击系统托盘图标进行快速控制
- **开机启动（管理员）**: 可设置为系统登录后以管理员权限静默启动
- **暂停/恢复**: 通过托盘菜单临时禁用/启用脚本
- **跨应用兼容性**: 适用于大多数 Windows 应用程序和输入法

## 系统要求

- Windows 7/8/10/11 (x64 或 x86)
- 已安装中文输入法 (微软拼音、搜狗、QQ拼音等)

## 安装方法

1. 从 [发布页面](#) 下载最新版本 (或自己构建)
2. 运行 `capslock-switcher-vX.X.X.exe`

## 注意事项

1. 此脚本的作用是将`CapsLock`映射到`Ctrl + Space`，因此需要先在设置中将输入法切换快捷键改为`Ctrl + Space`。
2. 托盘中的“开机启动（管理员）”会优先创建一个任务计划程序任务，以便在登录后静默地以最高权限运行。为避免登录过早启动时托盘图标偶发不显示，任务会在登录后延迟数秒再启动。首次开启该选项时，Windows 可能会弹出一次 UAC 确认。
3. “开机启动（普通）”只会把程序加入启动文件夹，不会申请管理员权限，因此在其他以管理员权限打开的应用中可能不会生效。
4. build.js脚本会自行寻找可能的AutoHotKey编译器位置，如果找不到的话，请将完整路径写在ahk-path.txt文件中。

## 使用方法

1. **基本切换**: 按下 `CapsLock` 键在中英文输入模式之间切换
2. **检查当前模式**: 按下 `Shift + CapsLock` 显示当前输入模式而不切换
3. **切换大写模式**: 按下 `Alt + CapsLock` 切换到原生 CapsLock 大小写，再按一次切回输入法模式
4. **托盘菜单**:
   - 右键点击托盘图标访问选项
   - "开机启动（管理员）": 切换 Windows 登录后通过任务计划程序自动启动
   - "开机启动（普通）": 切换 Windows 登录后通过启动文件夹自动启动
   - "切换到大写/切换到小写": 在原生 CapsLock 大小写模式和输入法切换模式之间切换
   - "重新启动": 以管理员权限重新启动当前程序
   - "退出": 退出应用程序

## 配置

该工具开箱即用，使用默认设置。高级用户可以修改：

1. **提示显示时间**: 修改脚本中的 `TOAST_HOLD_MS` (默认: 640毫秒)
2. **提示淡出速度**: 修改 `TOAST_FADE_INTERVAL_MS` 和 `TOAST_FADE_STEP`
3. **提示外观**: 修改 `ShowToast` 函数中的颜色和字体

## 故障排除

1. **脚本不工作**

   - 确保已安装 AutoHotkey v2.0
   - 检查输入法是否正在运行
   - 尝试以管理员身份运行
2. **提示不显示**

   - 检查脚本是否被暂停 (右键点击托盘图标)
   - 某些全屏应用程序可能会阻止提示通知
3. **管理员开机启动后没有托盘图标**

   - 这是因为程序可能在 Explorer 的通知区域准备好之前就启动了
   - 当前版本会给管理员计划任务加一个短延迟，避免托盘图标丢失
   - 如果你是在旧版本里已经开启过“开机启动（管理员）”，升级后请在托盘菜单里关闭一次再重新开启一次，让计划任务按新配置重建
4. **输入法未检测到**

   - 当前脚本支持中文语言布局 (zh-CN, zh-TW, zh-HK 等)
   - 其他语言输入可能需要修改代码
